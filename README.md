# Calculadora Web

Calculadora simples feita com HTML, CSS e JavaScript puro.

## Como executar

Abra o arquivo `index.html` em qualquer navegador. Não é preciso instalar nada.

## Funcionalidades

- Botões numéricos de 0 a 9
- Adição, subtração, multiplicação e divisão
- Botão `=` para mostrar o resultado
- Botão `C` para limpar
- Números decimais (botão `.`)
- Visor atualizado a cada clique
- Mensagem de erro na divisão por zero
- Layout responsivo (computador e celular)

## Arquivos

- `index.html`: estrutura da calculadora (visor e botões)
- `style.css`: aparência e layout responsivo
- `script.js`: lógica das operações



A lógica das contas foi feita com `switch`, sem usar `eval()`.
